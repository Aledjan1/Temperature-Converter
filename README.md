# 🌡️ Temperature Converter

An interactive Temperature Converter built with **HTML, CSS, and JavaScript**.

This project allows users to convert temperatures between Celsius (°C) and Fahrenheit (°F).

It is part of my ongoing JavaScript learning journey, where I focus on understanding programming logic and building projects independently.

## 🚀 Features

- Convert Celsius to Fahrenheit
- Convert Fahrenheit to Celsius
- Support positive, negative, and decimal temperatures
- Display results rounded to two decimal places
- Validate user input and display error messages
- Reset the input, selected unit, and result
- Clean and responsive user interface

My project link:  https://aledjan1.github.io/Temperature-Converter/
